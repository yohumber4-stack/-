# The Long Road

Однофайловая 3D-игра о поездке через пустыню в духе The Long Drive: процедурная пустыня и бесконечная трасса,
старая машина с физикой, съёмными деталями, топливом, маслом и водой в радиаторе, заброшенные заправки, мотели,
гаражи и военные базы с лутом, агрессивные кролики и оборванцы, смена дня и ночи, песчаные бури и грозы.
Все модели, текстуры, звуки и музыка генерируются кодом, внешних файлов нет.

## Как играть

Откройте **`TheLongRoad.html`** в Chrome, Edge или Firefox (нужен WebGL 2). Интернет не нужен.

| Действие | Клавиши |
| --- | --- |
| Ходьба / бег / присесть / прыжок | WASD, Shift, C, Пробел |
| Взять предмет / действие | ЛКМ / E |
| Выбросить, слоты инвентаря | Q, 1–4 |
| Фонарик | F |
| Зажигание (удерживать — стартер) | I |
| Газ / тормоз / руль, ручник | W / S / A D, Пробел |
| Передачи (механика) | R / F |
| Фары, сигнал, радио, настройка радио | L, H, N, [ ] |
| Камера (1-е / 3-е лицо), выглянуть | V, Z |
| Дневник, сон, пауза | J или Tab, X, Esc |

Все клавиши переназначаются в меню «Настройки → Управление».

## Сборка из исходников

```bash
npm install
npm run release   # собирает dist/index.html и копирует его в TheLongRoad.html
npm run dev       # локальный сервер с пересборкой: http://localhost:3000
```
